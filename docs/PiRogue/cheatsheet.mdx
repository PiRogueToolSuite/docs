# Cheatsheet

Not sure which version you run? See [Installation](/docs/PiRogue/installation).

## Default configuration

| Name | PiRogue 2.x | PiRogue 1.x |
|------|-------------|-------------|
| SSH port | `22` | `22` |
| SSH user | `pi` | `pi` |
| SSH password | `raspberry` (change it at the first login) | `raspberry` |
| Dashboard URL | `https://pirogue.local/dashboard` | `http://<PiRogue IP address>:3000` |
| Dashboard user | `admin` | `admin` |
| Dashboard password | randomly generated | `PiRogue` |
| Wi-Fi SSID | `PiRogue1` | `PiRogue1` |
| Wi-Fi password | randomly generated | `superlongkey` |

With PiRogue 2.x, retrieve the generated secrets on your PiRogue:

```bash title="PiRogue 2.x"
pirogue-admin-client wifi get-configuration
pirogue-admin-client dashboard get-configuration
```

With PiRogue 1.x, show the configuration with:

```bash title="PiRogue 1.x"
sudo pirogue-ctl config show
```

## Important files

| Name | Location |
|------|----------|
| SSH configuration | `/etc/ssh/sshd_config` |
| Suricata rules | `/var/lib/suricata/rules/suricata.rules` |
| PiRogue configuration (1.x) | `/var/lib/pirogue/config/pirogue.env` |
| PiRogue configuration (2.x) | `/var/lib/pirogue/admin/config.yaml` |
