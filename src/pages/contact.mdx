# Contact

Drop us an email, we read everything.

### General inquiries
To say hello or for general inquiries, write to **[hello@pts-project.org](mailto:hello@pts-project.org)**.

### Security issues
If you need to report a security issue, write to **[security@pts-project.org](mailto:security@pts-project.org)**.

### Purchasing a PiRogue
If you are interested in purchasing a PiRogue or have any question related to sales, write to **[sales@pts-project.org](mailto:sales@pts-project.org)**.

:::note

While we offer PiRogues for purchase, we prioritize supplying NGOs first.

:::
